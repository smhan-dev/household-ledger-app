# daypocket 보안·개인정보 점검

수입, 잔액, 빚, 지출 메모는 민감한 재정 정보로 다룹니다. 이 문서는 웹 프로토타입(`prototype/`)의 실제 데이터 흐름과 시험 결과를 기록합니다. Flutter 앱으로 옮길 때 다시 확인할 항목은 5장에 있습니다.

## 1. 데이터 흐름 (웹 프로토타입)
| 경로 | 무엇이 | 어디로 | 통제 방법 |
|---|---|---|---|
| 저장 | 프로필(잔액·월급·고정비·빚·저축), 지출 기록 | 브라우저 `localStorage` 키 `daypocket.v1` | 앱이 직접 읽고 씀. 암호화하지 않음 |
| 네트워크 | 없음 | — | CSP `connect-src 'none'`, `img-src 'self'`, `default-src 'none'`로 페이지에서 외부 요청을 막음 |
| 글꼴 | Pretendard | 같은 저장소의 `fonts/` | 외부 CDN을 쓰지 않음 (SIL OFL 1.1, `fonts/LICENSE.txt`) |
| 내보내기 | 지출 기록 CSV | 사용자가 고른 기기 폴더 | 사용자가 버튼을 눌러야만 생성. 이후 관리는 사용자 몫이라고 안내 |
| 로그·오류 수집 | 없음 | — | `console.log`, 분석 도구, 오류 수집 SDK 없음 |
| 공개 저장소 | 앱 코드, 샘플 데이터 생성 코드 | GitHub | 실제 재정 정보, 비밀키 없음 (아래 3장) |

**안내 문구와 일치시킨 점**
- 첫 화면 문구를 "이 폰 밖으로 한 발짝도 안 나가요. **직접 내보내기 전까지는요.**"로 바꿨습니다. CSV 내보내기가 유일하게 기기 밖으로 나가는 경로이기 때문입니다.
- "광고 추적 없음" 대신 실제로 강제되는 "외부 전송 차단"을 표시합니다.
- 계획 탭 하단에 "브라우저 데이터를 지우면 기록도 사라져요"를 표시합니다. 자동 백업이 없다는 약점을 숨기지 않기 위해서입니다.
- 전체 삭제 확인 창에 "이미 내보낸 CSV 파일은 지워지지 않아요"를 명시했습니다.

| 주간 잔액 | 주간 예산 − 월~일 지출 | 화면 값과 저장 데이터 합계 일치 |

## 3. 남은 위험과 판단
- **암호화하지 않음.** 프로토타입은 가짜 데이터로 화면을 확인하는 용도라 암호화는 넣지 않았습니다. 같은 기기의 브라우저를 열 수 있는 사람은 데이터를 볼 수 있습니다.
- **GitHub Pages 출처 공유.** `smhan-dev.github.io` 아래의 모든 프로젝트 페이지는 같은 출처라서 `localStorage`를 서로 읽을 수 있습니다. 지금은 모두 본인 저장소라 위험이 낮지만, 실제 재정 정보는 프로토타입에 넣지 않는 것을 권장합니다.
- **복원 기능 없음.** CSV는 사람이 보는 용도이고 다시 불러오는 기능은 없습니다. 휴대폰을 바꾸면 기록을 옮길 수 없습니다. 실제 앱에서 정할 문제로 남겨 둡니다(5장).
- **메모 길이 40자, 금액 9자리 제한.** 입력값 검증은 저장 시점과 불러오는 시점 모두에서 합니다.

## 4. 하지 않기로 한 것
아래는 현재 기획(계정 없음, 서버 없음, 개인 기기 저장)에서는 비용 대비 효과가 낮아 넣지 않았습니다.
- 서버 측 권한 검사, 계정 보안: 서버와 계정이 없습니다.
- 앱 잠금(PIN/생체인증): 웹 프로토타입에서는 의미가 없습니다. 실제 앱에서 선택 기능으로 검토합니다.
- 저장 데이터 암호화: 키를 잃으면 복구할 방법이 없어 백업 방식과 함께 정해야 합니다.

## 5. Flutter 앱으로 옮길 때 확인할 것
1. **안드로이드 자동 백업**: 기본값(`android:allowBackup`)이면 앱 데이터가 Google 드라이브로 백업됩니다. 허용할지 정하고, 허용하면 안내 문구를 "구글 계정 백업에 포함돼요"로 바꿉니다. 끄면 휴대폰 교체 시 데이터가 사라진다고 안내합니다.
2. **백업·복원 시험**: 백업을 제공하면 가짜 데이터로 내보내기 → 앱 삭제 → 복원 → 금액·기록 개수·주간 잔액 비교를 시험합니다.
3. **로그**: 릴리스 빌드에서 금액, 메모가 `print`/로그캣에 남지 않게 합니다.
4. **알림·위젯**: 잠금 화면 알림이나 홈 위젯에 금액을 보여줄 경우 잠금 화면 표시 여부를 설정할 수 있게 합니다.
5. **권한**: 인터넷 권한이 필요 없으면 매니페스트에서 빼서 "외부 전송 차단"을 OS 수준에서 보장합니다.
6. **기능이 추가될 때 새로 설계할 것**: 로그인·동기화·가족 공유(서버 권한 검사), 카드 알림 읽기(알림 접근 권한, 플레이 정책), 광고·분석 SDK(수집 항목 공개), 유료 구독(결제 검증).
